# Recovered Conspiracy + Headline Cards — other campaigns

Primary retrieval: `https://r.jina.ai/<scribd-url>` proxy, which returns the Scribd text layer for pages 1–3. Two source docs were found by the same uploader (`umesh9s1998`), each 3 pages, and cover the **Earth 2040 deck** exclusively.

Sources used:

- `https://r.jina.ai/https://www.scribd.com/document/915391788/2040-Deck-CC` (Scribd doc 915391788, "2040 Deck CC", 3pp)
- `https://r.jina.ai/https://www.scribd.com/document/915391789/2040-Deck-HC` (Scribd doc 915391789, "2040 Deck HC", 3pp)

Deck-wide preamble text from CC:

> Conspiracy cards can be used during your turn phase or just before an opponent answers his/her ideology card. For convenience please declare once if using a conspiracy card outside your turn so players can pause their answer and if doing so do so quickly.
> The term voter implies majority, minority, and chaos voters but not volatile voters.
> If there are no voters to discard then effect is over.

Deck-wide preamble text from HC:

> Headlines cards are always carried out chronologically and in the post turn phase. Unless clearly stated that its effect is for a round or more than 1 turn.
> Headlines can be blocked if their effect is limited to a player's turn but if the headline involves a couple of turns or round having multiple players then the block has to be applied at the very beginning.
> If a headline donates you voters, they must be placed immediately before going to the next player or the next turn.
